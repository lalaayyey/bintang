Laporan Praktikum: Form Pendaftaran Flutter

Deskripsi Singkat

Tugas ini membahas cara membuat form pendaftaran sederhana di Flutter dengan empat kolom input: Nama, Email, Password, dan Confirm Password, serta satu tombol Submit. Fokus utamanya adalah menerapkan validasi input langsung di layar dan memisahkannya ke dalam struktur file yang rapi.

Ketentuan Input & Validasi

  • Nama: Tidak boleh kosong.
  • Email: Wajib diisi dan harus menggunakan format yang benar (mengandung @).
  • Password: Tidak boleh kosong.
  • Confirm Password: Harus sama dengan isi kolom Password.
  • Tombol Submit: Saat diklik, sistem akan mengecek semua inputan. Jika semua sudah sesuai, pesan konfirmasi (SnackBar) akan muncul di layar.

Struktur File

Kode dibagi menjadi dua file Dart sesuai instruksi:

  • main.dart — Sebagai file utama untuk menjalankan aplikasi dan mengatur tema.
  • user_registration_form.dart — Berisi tampilan form, controller, dan fungsi validasinya.

Cara Kerja Form

  1. Pengguna mengisi kolom nama, email, password, dan konfirmasi password.
  2. Pengguna menekan tombol Submit.
  3. Sistem mengecek isi setiap kolom:
    • Jika ada isi yang salah atau kosong, teks peringatan akan muncul di bawah kolom tersebut.
    • Jika semua sudah benar, sistem akan menampilkan notifikasi SnackBar sebagai tanda berhasil.

Kode Program

1. main.dart
2. user_registration_form.dart
